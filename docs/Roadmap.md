# ERP Nexus API

## Visão Geral

O ERP Nexus API é uma API REST desenvolvida em Delphi utilizando o framework Horse.

Objetivo:

Construir uma API moderna seguindo boas práticas de arquitetura em camadas, SOLID, Clean Code e metodologias ágeis.
